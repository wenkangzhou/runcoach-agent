# 跑步心率区间与训练强度

## 什么是心率区间？

心率区间是根据最大心率（Max HR）或储备心率（HRR）划分的训练强度范围。常见划分方式：

- **Z1（恢复区）**: 50-60% Max HR，非常轻松，用于恢复和热身
- **Z2（有氧基础区）**: 60-70% Max HR，可以聊天的配速，堆有氧容量的主战场
- **Z3（节奏区）**: 70-80% Max HR，略感吃力，乳酸开始积累
- **Z4（阈值区）**: 80-90% Max HR，很难受，接近乳酸阈值
- **Z5（无氧区）**: 90-100% Max HR，冲刺和间歇

## 如何计算最大心率？

常用公式：
- 简单公式：220 - 年龄
- Tanaka 公式：208 - 0.7 × 年龄
- 更精确：实际测试（如 3km 全力跑后的心率峰值）

## 各区间训练目的

### Z1-Z2（轻松跑）
- 占周跑量的 70-80%
- 提升有氧耐力、脂肪代谢效率
- 促进恢复、降低受伤风险
- 配速建议：比马拉松配速慢 45-90 秒

### Z3（节奏跑 / Tempo）
- 占周跑量的 10-15%
- 提升乳酸阈值，延长高强度持续时间
- 配速建议：比马拉松配速慢 15-30 秒
- 单次时长：20-40 分钟

### Z4（阈值跑 / Threshold）
- 占周跑量的 5-10%
- 直接提升乳酸阈值
- 配速建议：接近或等于马拉松配速
- 单次时长：10-20 分钟，可拆分为 2×10min

### Z5（间歇 / Interval）
- 占周跑量的 5%
- 提升最大摄氧量（VO2max）和跑步经济性
- 配速建议：比 5km 配速快 5-10 秒
- 单次时长：3-5 分钟，休息时间为跑时的一半到相等

## 常见误区

1. **跑太快**：80% 的跑者 80% 的时间跑在 Z3，而不是 Z2。这导致有氧基础不牢，恢复不足。
2. **忽视 Z1**：觉得"太慢没效果"，但 Z1 是恢复和毛细血管增生的关键。
3. **Z5 太多**：间歇很爽，但过量会透支身体，增加伤病风险。

## 实用建议

- 新手：90% Z1-Z2，10% Z3
- 进阶（目标全马 3:30-4:00）：80% Z1-Z2，15% Z3，5% Z4-Z5
- 精英（目标全马 3:00 以内）：70% Z1-Z2，20% Z3-Z4，10% Z5

## 如何判断自己在哪个区间？

- **说话测试**：Z2 可以完整说句子；Z3 只能说短语；Z4 只能说单词；Z5 说不出话
- **呼吸节奏**：Z2 鼻吸鼻呼；Z3 鼻吸口呼；Z4-Z5 口吸口呼
- **主观感受**：Z2 "轻松"；Z3 "有点累但还能坚持"；Z4 "很难受"；Z5 "极限"
