# 马拉松补给策略

## 基本原则

马拉松补给的核心是：**提前补充，不要等到饿了/渴了才补。**

身体吸收和利用能量需要时间，胃排空碳水化合物约需 15-30 分钟。因此：
- 能量胶：赛前 15 分钟吃第一支，之后每 30-45 分钟一支
- 水/电解质：每 5km 或每个补给站都喝，少量多次

## 能量胶使用指南

### 什么是能量胶？

能量胶是浓缩的碳水化合物（主要是麦芽糊精和果糖），约含 20-25g 碳水，100-120 大卡。

### 不同完赛时间的胶量

| 完赛时间 | 建议胶量 | 具体方案 |
|---------|---------|---------|
| 2:30-3:00 | 4-5 支 | 赛前 15min + 10km + 20km + 30km + 35km |
| 3:00-3:30 | 5-6 支 | 赛前 15min + 8km + 16km + 24km + 32km + 38km |
| 3:30-4:00 | 5-6 支 | 赛前 15min + 8km + 16km + 24km + 32km + 38km |
| 4:00-5:00 | 4-5 支 | 赛前 15min + 10km + 20km + 30km + 38km |
| 5:00+ | 3-4 支 | 赛前 15min + 12km + 24km + 36km |

### 吃胶技巧

1. **配水吃**：每支胶配 150-200ml 水，不要配运动饮料（糖分叠加可能导致胃不适）
2. **提前练习**：比赛前至少 3 次长距离训练中测试你选的胶品牌和口味
3. **不要试新**：比赛当天不要用没试过的品牌或口味
4. **含咖啡因的胶**：建议只在最后 10km 使用，作为"提神武器"

## 水和电解质

### 补水策略

- **赛前**：比赛前 2-3 小时喝 400-600ml 水；赛前 15 分钟再喝 200ml
- **赛中**：每 5km 或每个补给站喝 100-150ml，少量多次
- **不要等渴了再喝**：口渴已经是轻度脱水的信号

### 电解质（盐丸）

- 出汗多的跑者（衣服上有白色盐渍）需要额外补充电解质
- 建议：每 10km 或每小时 1-2 粒盐丸
- 如果比赛天气热（>25°C），增加盐丸频率

## 比赛日早餐

- **时间**：赛前 2-3 小时吃完
- **内容**：以碳水为主，低脂低纤维低蛋白
  - 好选择：白面包、香蕉、燕麦粥、能量棒
  - 避免：全麦面包（纤维多）、培根（脂肪多）、牛奶（部分人不耐受）
- **量**：平时早餐的 70-80%，不要吃到撑

## 常见错误

1. **吃太多**：胃需要血液消化，吃太多会分散肌肉供血，导致跑不动
2. **喝太少**：脱水 2% 就会显著影响表现
3. **比赛试新**：比赛当天第一次吃某品牌胶 = 大概率胃痉挛
4. **只喝运动饮料不喝水**：运动饮料糖分高，需要稀释，纯喝可能导致胃不适

## 个性化调整

每个人的胃耐受度不同，需要在训练中测试：
- 哪些品牌的胶不反胃？
- 多久吃一支最舒服？
- 需要盐丸吗？多少？
- 赛前早餐吃什么不胀气？

**记住：比赛当天的补给策略，应该是你训练中最舒服的那套，而不是理论上最优的那套。**
